## 버그 수정

- **Awake: 모듈을 끈 직후 잠자기 방지가 다시 켜질 수 있던 문제**
  - 자동 모드에서 에이전트 감지가 진행되는 도중에 Awake 모듈을 끄면, 감지가 끝난 뒤 잠자기 방지와 뚜껑 닫힘 방지가 다시 켜질 수 있었습니다. 이제 모듈을 끈 뒤에는 어떤 작업도 잠자기 방지를 다시 켜지 않습니다.

## 내부 개선 (동작 변화 없음)

- **이벤트 탭 처리 통합**: Windows(수정키 + 드래그), Mouse(측면 버튼·스크롤), Switcher(⌥Tab)가 각자 갖고 있던 이벤트 탭 관리 코드를 하나로 합쳤습니다. 손쉬운 사용 권한이 사라지면 3초 안에 탭을 스스로 해제해 입력이 멈추지 않게 하는 안전장치가 세 모듈에서 똑같이 동작합니다.
  - ⚠️ 이 변경은 실제 기기에서 아직 확인하지 못했습니다. 수정키 드래그, 마우스 측면 버튼·스크롤, Switcher가 이전과 다르게 동작하면 [이슈](https://github.com/mordol/T-Utilities/issues)로 알려 주세요.
- **사전 창 크기·위치 저장 위치 변경**: 다른 모듈 설정과 같은 방식으로 저장하도록 바꿨습니다. 기존에 저장된 크기와 위치는 처음 실행할 때 자동으로 옮겨집니다.
- **모듈 독립성 규칙과 자동 검사 추가**: 각 기능(모듈)이 서로 영향을 주지 않도록 규칙을 정리하고([Docs/MODULES.md](https://github.com/mordol/T-Utilities/blob/main/Docs/MODULES.md)), 릴리스 전에 자동으로 검사합니다. 기여하실 때 참고해 주세요.

## 업데이트 방법

- v0.1.2 이상: 팝오버의 **New update** 버튼 또는 설정 → 일반 → "지금 확인".
- Homebrew: `brew upgrade --cask t-utilities` (앱을 종료한 뒤 실행하세요).
