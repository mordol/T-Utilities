## 새 기능

- **베타 기능 표시 설정**
  - 설정 → 일반에 **"베타 기능 표시"**가 생겼습니다(기본 꺼짐). 켜면 개발 중인 모듈이 설정과 팝오버 목록에 나타납니다.
  - 베타 모듈은 표시한 뒤에도 각 모듈 설정에서 켜야 동작합니다. 다시 숨기면 실행 중이던 베타 모듈이 멈춥니다.

- **Remote (베타): Tailscale로 다른 Mac 원격 제어**
  - 다른 프로그램 없이 T-Utilities끼리 Mac 화면을 보고 마우스·키보드로 조작합니다. 두 Mac이 같은 Tailscale 네트워크에 있어야 합니다.
  - **켜는 방법**: 설정 → 일반 → "베타 기능 표시"를 켜고, 설정 → Remote에서 모듈을 켭니다. 두 Mac 모두 v0.1.16 이상이어야 합니다.
  - **접속받는 Mac(호스트)**: 팝오버의 Remote 줄 스위치(또는 설정의 "이 Mac에 원격 접속 허용")를 켭니다. 기본은 꺼짐입니다. **화면 기록**과 **손쉬운 사용** 권한이 필요합니다.
  - **접속하는 Mac**: 팝오버의 Remote 줄을 눌러 펼치면 Tailscale에 있는 Mac 목록이 나오고, 누르면 새 창에 상대 화면이 보입니다. 목록에 없는 Mac은 설정에서 MagicDNS 이름이나 100.x 주소로 추가할 수 있습니다.
  - **해상도**: 전송 폭을 1280~2560px 중에서 고를 수 있고(기본 1920), 접속 중에도 창 제목 표시줄에서 바꿀 수 있습니다. 최대 30fps입니다.
  - **잠긴 Mac**: 잠금 화면이 보이고 암호를 입력해 잠금을 풀 수 있도록 만들었습니다. 실기기 확인이 필요한 부분이라 결과를 알려 주세요. (로그아웃 상태의 로그인 화면은 지원하지 않습니다.)
  - **보안**: 접속은 Tailscale 주소(100.x)에서만 받고 tailnet 밖의 연결은 거절합니다. 승인 팝업은 없으므로, 스위치를 켜 두면 같은 tailnet의 기기가 이 Mac을 조작할 수 있습니다. 동시 접속은 1개이고, 10분 동안 입력이 없으면 연결을 끊습니다.
  - 접속받는 동안 메뉴 막대 아이콘 옆에 **"원격"**이 표시되고, 팝오버·우클릭 메뉴·설정에서 바로 끊을 수 있습니다. 세션 중에는 화면이 꺼지지 않습니다.
  - 오디오, 파일 전송, 클립보드 공유는 아직 없습니다. 문제가 있으면 [이슈](https://github.com/mordol/T-Utilities/issues)로 알려 주세요.

## 업데이트 방법

- v0.1.2 이상: 팝오버의 **New update** 버튼 또는 설정 → 일반 → "지금 확인".
- Homebrew: `brew upgrade --cask t-utilities` (앱을 종료한 뒤 실행하세요).
