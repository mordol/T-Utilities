## 새 기능

- **업데이트가 있으면 메뉴 막대 아이콘에 표시**
  - 새 버전이 나오면 메뉴 막대 아이콘 오른쪽 아래에 위쪽 화살표(↑)가 든 작은 동그라미가 붙습니다(Tailscale과 같은 방식). 팝오버를 열지 않아도 업데이트가 있는지 알 수 있습니다.
  - 표시는 메뉴 막대 색(라이트·다크)을 따르고, Awake처럼 아이콘이 바뀌는 상태에서도 그 아이콘 위에 붙습니다.
  - 업데이트를 설치하면 사라집니다. 업데이트 확인은 지금처럼 하루에 한 번(또는 설정 → 일반 → "지금 확인") 합니다.
  - 이 표시는 이번 버전부터 들어가므로, 다음 버전이 나올 때부터 보입니다.

- **Clipboard: 번역**
  - 클립보드 항목에 마우스를 올리면 **번역 버튼**이 나옵니다(이미지는 OCR 버튼 옆). 누르면 커서 근처에 번역 창이 뜨고, **클립보드로 복사** 버튼으로 결과를 복사할 수 있습니다. 번역 창은 지금 쓰던 앱의 포커스를 빼앗지 않으며 Esc로 닫힙니다.
  - **⌃⌥T**: 클립보드의 첫 번째 항목을 번역합니다. 단축키는 설정 → 일반에서 바꿀 수 있습니다.
  - **이미지**는 기기 안에서 OCR한 뒤 번역합니다. 읽어 낸 텍스트는 클립보드에도 저장됩니다(설정에서 끌 수 있음). 텍스트를 찾지 못하면 번역 창에 안내가 나오고 5초 뒤 자동으로 닫힙니다.
  - **상호 번역**: 원문이 기본 언어(기본 한국어)면 상대 언어(기본 영어)로, 그 밖의 언어는 기본 언어로 번역합니다. 두 언어는 설정에서 고를 수 있습니다.
  - **번역 지침**: 존댓말, 용어 처리 같은 원하는 번역 방식을 설정에 적어 두면 매번 반영합니다.
  - **번역 엔진** (설정 → Clipboard → 번역)
    - **구독 CLI**: Mac에 설치하고 로그인한 Claude Code, Codex, Cursor CLI를 사용합니다. API 키가 필요 없습니다. 기본값은 Claude Code CLI입니다.
    - **API**: Claude, OpenAI, Gemini API 키를 입력해 사용합니다. 키는 macOS 키체인에 저장됩니다.
    - 모델은 엔진마다 바꿀 수 있습니다.
  - 번역할 텍스트는 선택한 엔진의 서비스로 전송됩니다. CLI는 파일 읽기, 도구, MCP, 세션 저장을 모두 끈 상태로 실행합니다.
  - ⚠️ 실제 기기에서 충분히 확인하지 못한 채 릴리스했습니다. 문제가 있으면 [이슈](https://github.com/mordol/T-Utilities/issues)로 알려 주세요.

## 업데이트 방법

- v0.1.2 이상: 팝오버의 **New update** 버튼 또는 설정 → 일반 → "지금 확인".
- Homebrew: `brew upgrade --cask t-utilities` (앱을 종료한 뒤 실행하세요).
