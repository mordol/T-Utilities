## 새 기능

- **Windows: 창을 위아래로 꽉 채우기** (#27, 요청 @gyuha)
  - **⌃⌥↑**: 현재 창의 가로 위치와 폭은 그대로 두고, 높이만 화면 위아래(메뉴 막대 아래부터 Dock 위까지)에 꽉 채웁니다.
  - **⌃⌥↓**: 채우기 전의 위치와 높이로 되돌립니다. 채운 뒤 창을 좌우로 옮겼다면 옮긴 가로 위치는 그대로 두고 높이만 되돌립니다.
  - 채운 창에서 ⌃⌥↑를 다시 눌러도 처음 크기를 기억하므로 ⌃⌥↓로 원래대로 돌아갑니다. 채운 적 없는 창에서 ⌃⌥↓를 누르면 경고음이 납니다.
  - 단축키는 설정 → 일반에서 바꿀 수 있습니다.
  - ⚠️ 실제 기기에서 확인하지 못한 채 릴리스했습니다. 문제가 있으면 [#27](https://github.com/mordol/T-Utilities/issues/27)에 알려 주세요.

## 업데이트 방법

- v0.1.2 이상: 팝오버의 **New update** 버튼 또는 설정 → 일반 → "지금 확인".
- Homebrew: `brew upgrade --cask t-utilities` (앱을 종료한 뒤 실행하세요).
