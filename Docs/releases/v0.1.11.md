## 버그 수정

- **Mouse: USB 리시버를 다시 연결하면 포인터 설정이 적용되지 않던 문제**
  - 마우스 USB 리시버를 뺐다가 다시 꽂으면 설정 → Mouse에 "적용 실패: USB Receiver"가 표시되고, 속도·가속이 macOS 기본값으로 돌아간 채 남아 있었습니다. 지금까지는 Mouse 모듈을 껐다 켜야 다시 적용됐습니다.
  - 원인은 앱이 처음 본 장치 목록을 계속 써서, 다시 연결된 리시버 대신 이미 사라진 장치에 값을 쓰던 것이었습니다. 이제 마우스가 새로 연결되면 장치 목록을 새로 읽어 1~3초 안에 설정을 다시 적용합니다.
  - 블루투스 마우스를 다시 연결하거나 잠자기에서 깨어날 때도 같은 방식으로 다시 적용됩니다.

## 업데이트 방법

- v0.1.2 이상: 팝오버의 **New update** 버튼 또는 설정 → 일반 → "지금 확인".
- Homebrew: `brew upgrade --cask t-utilities` (앱을 종료한 뒤 실행하세요).
