## 변경 사항

- **Remote 정식 기능으로 전환**
  - 두 Mac에서 확인을 마쳐 베타 표시를 뗐습니다. 이제 "베타 기능 표시"를 켜지 않아도 설정 → Remote에서 켤 수 있습니다(기본 꺼짐).
  - 잠긴 Mac에 접속하면 잠금 화면이 보이고, 암호를 입력해 잠금을 풀 수 있습니다.
  - v0.1.16에서 베타로 켜 두었다면 그대로 켜져 있습니다.

- **Remote: macOS 방화벽 안내**
  - macOS 방화벽이 켜져 있으면 처음 접속받을 때 "들어오는 네트워크 연결을 허용하시겠습니까?" 창이 나옵니다. **허용**을 눌러야 접속할 수 있습니다.
  - 설정 → Remote의 호스트 섹션에 방화벽 상태(허용됨 / 아직 묻지 않음 / 차단됨)가 표시됩니다. 차단돼 있으면 고치는 방법과 **방화벽 설정 열기** 버튼이 나옵니다.
  - 접속에 실패하면 상대 Mac의 방화벽이 막고 있을 수 있다는 안내도 함께 보여 줍니다.

## 업데이트 방법

- v0.1.2 이상: 팝오버의 **New update** 버튼 또는 설정 → 일반 → "지금 확인".
- Homebrew: `brew upgrade --cask t-utilities` (앱을 종료한 뒤 실행하세요).
