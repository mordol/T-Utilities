## 새 기능

- **Windows: 창을 화면 왼쪽·오른쪽 절반으로** (#26, 요청 @gyuha)
  - **⌃⌥←**: 현재 창을 화면 왼쪽 절반에 채웁니다.
  - **⌃⌥→**: 현재 창을 화면 오른쪽 절반에 채웁니다.
  - 창이 있는 디스플레이의 메뉴 막대와 Dock을 뺀 영역을 기준으로 나눕니다. 크기를 바꿀 수 없는 창은 크기를 유지한 채 해당 절반의 가운데로 옮깁니다.
  - 단축키는 설정 → 일반에서 바꿀 수 있습니다. Rectangle의 기본 단축키와 같아서 Rectangle이 실행 중이면 충돌하니 종료하세요.
  - ⚠️ 실제 기기에서 확인하지 못한 채 릴리스했습니다. 문제가 있으면 [#26](https://github.com/mordol/T-Utilities/issues/26)에 알려 주세요.

## 업데이트 방법

- v0.1.2 이상: 팝오버의 **New update** 버튼 또는 설정 → 일반 → "지금 확인".
- Homebrew: `brew upgrade --cask t-utilities` (앱을 종료한 뒤 실행하세요).
